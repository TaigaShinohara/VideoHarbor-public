# VideoHarbor UI カタログ

本ドキュメントは `meaningful_app_design` スキルに基づく VideoHarbor の主要 UI パーツの正本です。新しい UI を作る前・調整する前は必ず本カタログを確認し、流用またはバリエーション展開を基本としてください。

## 画面ごとの意味

1. **「動画を保存」画面**
   - **主役**: 検出された保存候補カード（`.video-group` / `.video-card`）と保存ボタン
   - **狙う気持ち**: 目的の動画がすぐに見つかり、迷わず安全な形式で保存できる安心感
   - **主な手段**: サムネイル＋タイトルのグループ化、形式セレクト、詳細情報の折り畳み
2. **「録画する」画面**
   - **主役**: 録画プレビュー＆操作パネル（`.preview-stage` / `.record-panel`）と開始ボタン
   - **狙う気持ち**: どの対象を・音声あり/なしで録画しているかが一目で分かり、確実に止められるコントロール感
   - **主な手段**: 3つの対象タイル、録画中の固定操作パネル、実時間・容量の等幅数値表示
