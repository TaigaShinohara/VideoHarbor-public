# VideoHarbor アート方針（Art Direction）

本ドキュメントは `meaningful_app_design` スキルに基づく VideoHarbor のアート方針の正本です。UI の設計・調整・レビュー時は必ず本書を参照してください。

## 1. アプリ全体の意味

- **一番見せたいもの（主役）**: 対象ページから見つかった「今すぐ保存または録画できる動画」と、その実行操作。
- **どう思ってほしいか（狙う気持ち）**: 「余計な心配や迷いなく、安全に・確実に自分の手元へ動画を残せた」という静かな安心感とコントロール感。
- **それを実現する主な手段**:
  - 「動画を保存」「録画する」の2画面に役割を明確に分離し、1画面1目的に絞る。
  - 取得元ドメイン・形式・処理状態を隠さず淡々と示し、危険や制約は誠実に伝える。
  - 装飾や煽り文句を排し、落ち着いたハーバーティール（深緑青）と十分な余白で認知負荷を抑える。

## 2. 世界の言葉（雰囲気キーワード）

### 目指す雰囲気（3つのキーワード）
1. **静謐な港（Calm Harbor）**: 派手な主張をせず、動画を受け止めて安全に停泊させる道具としての落ち着き。
2. **明晰・誠実（Clear & Honest）**: できること・できないこと・処理中の状態を誤魔化さず、短い言葉と整った階層で伝える。
3. **軽快な実務道具（Crisp Utility）**: ブラウザ拡張機能として素早く開き、迷わず操作を終えられる軽やかさ。

### やらない雰囲気
- 過剰な装飾・ネオン・サイバーパンク調・動画サイト風の派手なエンタメ演出。
- 不安を煽る過剰な警告色や、常設の長文ガイドによる圧迫感。
- 処理の進行を誤魔化すような過剰なアニメーションや、意味のない装飾アイコン。

## 3. 色の性格

- **ベース（紙面・背景）**: 清潔な白（`#ffffff`）を主紙面とし、わずかに青緑を含んだオフホワイト（`#f6f8f7` / `#f4f8f6` / `#fafcfb`）で階層を分ける。純粋な無彩色グレーではなく、わずかにティールを帯びたニュートラルを使うことで全体の温度感を統一する。
- **文字（インク）**: 真っ黒（`#000000`）を避け、深い森のようなスレートグリーン（`#1e332e`）を本文に、落ち着いたセージグレー（`#586c64`）を補助情報に用いる。
- **アクセント（港のティール）**: `#0e7a68`（ホバー時 `#0a6354`）。主要ボタン、選択状態、フォーカスリング、進捗にのみ使い、1画面内で主役が1つに浮かぶよう使用箇所を絞る。
- **意味の色（セマンティックカラー）**:
  - **成功 / 再生中**: 落ち着いたエメラルド（`#0d6e42` / `#daf3e5`）で「今動いている・完了した」ことを静かに示す。
  - **注意 / 確認**: 温かみのあるアンバー（`#875c12` / `#fffbf2`）で、権限確認や音声未取得など「立ち止まって確認してほしい場面」に限定して使う。
  - **危険 / 停止 / エラー**: 彩度を抑えたクリムゾン（`#aa3e43` / `#fff5f5`）で、録画停止やエラーを明確に伝える。

## 4. 形の言語

- **角丸**: 要素のスケールに合わせて `8px`（小・ボタン・入力）、`12px`（中・カード・パネル）、`16px`（大・空状態）の3段階を使い分ける。
- **線と影**: 基本は `1px` の繊細な境界線（`#dbe3df` / `#edf2ef`）で領域を区切る。影は浮遊パネル（録画パネル・保存進捗パネル）やホバー時のカードにのみ最小限（`--shadow-sm` / `--shadow-md`）を添え、過剰な立体感を作らない。
- **アイコンとイラスト**: `1.8px` ストロークの丸みのある線画アイコン（`icons.svg`）で統一する。アプリアイコンのみ Liquid Glass の専用アイコンを使用し、ツールバー・ヘッダーで世界観の起点とする。

## 5. 文字と密度の方針

- **フォント**: システム標準のサンセリフ（`-apple-system`, `BlinkMacSystemFont`, `"Segoe UI"`, `"Noto Sans JP"`）を用い、環境ごとの読みやすさと高速な描画を優先する。
- **数値**: 録画時間・容量・件数には `font-variant-numeric: tabular-nums` を適用し、変化してもガタつかないようにする。
- **密度**: 1画面に情報を詰め込みすぎず、詳細情報（URL・解像度・ヘルプ・履歴）は `<details>` で畳む。主役と補助（2〜3個）が3秒で視認できる余白を保つ。

## 6. 動きの性格

- **意味のある短い動きだけ**: タブ切替やカード出現の `reveal`（160〜180ms）、ボタンの押下感（`translateY(1px)`）、スキャン中・録画中の状態を示す `spin` / `pulseDot` のみに限定する。
- **視差効果の尊重**: `prefers-reduced-motion: reduce` 時はすべてのアニメーションとトランジションを無効化する。

## 7. コンセプトとアートの根拠マップ

| コンセプトの要素 | アートの選択 | 理由 |
| :--- | :--- | :--- |
| 完全ローカル・外部送信ゼロの信頼性 | 落ち着いたティール＋白紙面＋誠実な注意色 | 怪しさを排除し、安心して使える道具感を作るため |
| 保存と録画の2目的分離 | セグメントタブ＋目的別2画面 | 迷わず最短で目的の操作に辿り着けるようにするため |
| モバイル / デスクトップ両対応 | セーフエリア追従＋十分なタップ領域 | 片手操作や狭い画面でも誤操作を防ぐため |

## 8. 良い例 / 悪い例

- **良い例**: 保存候補のカードで「タイトル・形式選択・保存ボタン」だけがすぐ目に入り、細かい技術情報（配信元・寸法）は「詳細」に畳まれている状態。
- **悪い例**: すべてのカードに赤い警告バッジや長い説明文が常時並び、どれを押せば保存できるか一目で分からない状態。
